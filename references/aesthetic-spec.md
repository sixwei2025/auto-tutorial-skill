## 二、EyeCannndy 运镜与景别交替铁律（彻底告别 PPT 幻灯片）

1. **单镜头停留上限**：同一景别、同一张静态图停留 **严禁超过 3.0 秒** 不做景别或构图变化。
2. **景别交替律**：连续镜头必须遵循 **「全景定调 → 中景叙事 → 极微距特写」** 交替推进，同一张高分辨率素材可拆出 2~3 个不同局部特写镜头（如先拍局部细节，再切另一侧配角，最后拉回全景）。
3. **标准运镜词库**：
   - **Crash Zoom（急推冲击）**：在 `0.25s` 内从 `1.0x` 快速推近至 `1.6x~2.0x` 聚焦核心文字或按钮，配合重低音音效。
   - **Connected Pan（连贯平移）**：同一画面内多个重点依次讲解时，直接平滑平移镜头过去，严禁反复拉回 `1.0x` 晃眼。
   - **Whip Pan（甩镜转场）**：横向快速扫过伴随动态模糊（Motion Blur）切入下一幕。
   - **Match Cut（同构转场）**：上一镜头的圆形/线条主体，在下一镜头无缝衔接同位置的圆形/线条主体。
4. **缓动曲线硬标准（禁用匀速 `linear`）**：
   - **入场（急入缓停）**：`cubic-bezier(0.16, 1, 0.3, 1)`
   - **退场（缓出急收）**：`cubic-bezier(0.7, 0, 0.84, 0)`
   - **Remotion Spring 默认**：`{ damping: 14, stiffness: 180, mass: 0.8 }`（克制弹性，不拖泥带水）

## 三、Utopia & Butterick 排印与字号阶梯

1. **数学比例字号阶梯（严禁拍脑袋填字号）**：
   - 采用 **大三度（1.25x）** 或 **纯四度（1.333x）** 比例拉开层级：
     - 16:9 横屏参考：`字幕 34~38px` → `卡片正文 44px` → `模块小标 56px` → `主视觉大标 72~96px`
     - 3:4 / 9:16 竖屏参考：`字幕 42px` → `卡片正文 52px` → `主标题 84~110px`
2. **排版安全边界与呼吸感**：
   - **单行字数**：底部字幕单行不超过 **18 个汉字**，最多两行，行高 `1.35 ~ 1.5`。
   - **电影感字幕安放**：16:9 高级感大片优先采用 **2.35:1 电影遮幅（上下纯黑边）**，将极简字幕放在底部黑边内，**严禁用土味半透明灰黑矩形条糊住主画面**。
   - **安全边距**：所有文字与核心信息距离画幅边缘至少保留 **8%** 留白。

## 四、Radix 12 级语义配色与品牌色节制

1. **配色层级**：参考 Radix Colors 逻辑，严格区分「背景底色（低饱和极暗/极浅）→ 卡片表面 → 1px 细分割线 → 强调色 → 主文字」。
2. **克制用色**：同一画面主色调不超过 **2 种**；高饱和强调色（如汇芯红 `#C8102E`、高定金 `#D4AF37`、荧光黄 `#F5D061`）全屏面积占比 **不超过 10%**，只用于点睛、划重点与价格/数据反转。

## 五、成片交付前 5 秒审美自检清单

- [ ] **0.01s 首帧定格**：是否第一帧就有强视觉主体与清晰冲突标题，无黑屏/无意义过渡？
- [ ] **幻灯片排查**：是否有任何静态图干放超过 3 秒没有景别切换或动态粒子/光效？
- [ ] **字号层级**：主标题与正文字号差距是否至少达到 `1.5 倍` 以上？
- [ ] **字幕纯净度**：字幕是否遮挡了画面核心主体？是否控制在每行 ≤18 字？
- [ ] **调色与音效**：画面暗角/色调是否统一？关键转场和出字是否有声效呼应？
