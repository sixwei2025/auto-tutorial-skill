# 制作协作

默认由当前操作者完成真实软件操作，不能让多个操作者争用桌面。仅在用户或适用规则授权并行分工时，才委派互不干扰的封面、声音或审阅；授权更新技能不等于授权制作新视频或批量。

统一使用一个绝对ROOT和同一份camera.json、captions.json。镜头按实际声音对齐，全片已统一1.35倍速，不在合成时重复变速。走fullscreen.py与check_fullscreen.py，禁止协作者另套旧标题栏或第二层缩放。可用剪辑技能仅辅助必要转换，不另造时间线；原图、成品和来源记录保留，人工观察如实登记。

协作硬边界：所有参与工具沿用主技能v3.3.0的禁录屏规则。ffmpeg-skill只处理已有合格截图、指定配音、实际作品视频与直接渲染的图解；不采集屏幕、不调用花录，不接收误录的操作视频作为正文或抽帧来源。统一主渲染器为fullscreen.py，render.py仅用于历史兼容，不作为新项目交接入口。
