# 爆款标题方法论（WorkBuddy 专用）

一句话：不是临场灵感，是「七要素标注 + 成稿过闸 + 定稿一字不改」。

## 总原则

1. 六招主框架：贴标签、设悬念、造冲突、做留白、撩色欲、送好处；加借势，合称七要素。
2. 每标题标出用了哪几招，**叠 2–3 招最好**。
3. 点名、用数字；公开报道里的事实才写，不造谣。
4. 标题承诺什么，正文必须兑现。
5. 尽量 ≤20 汉字（12–18 更优）；不用违禁词，不承诺收益。
6. **涉 WorkBuddy 的必须带 WorkBuddy**（高权流量词，优化先改冲突/悬念，永不先砍品牌词）。

## 七要素

| 要素 | 做法 | 例 |
|---|---|---|
| 贴标签 | 出现目标人群身份词 | 一人公司老板，别再什么都自己干 |
| 设悬念 | 只说一半 | 用了 3 天，我把它卸了 |
| 造冲突 | 反常识、对比、站队 | 免费的赢了 199 的 |
| 做留白 | 半截判断或省略号 | 这个功能，我劝你先别开 |
| 撩色欲 | 暧昧双关，不低俗 | （评测类成稿不用） |
| 送好处 | 方法、清单、避坑 | 只送方法，不送收益承诺 |
| 借势 | 热词、大厂、已验证高权产品名 | WorkBuddy 一句话出 PPT |

口诀：冲突或留白至少占一个；借势能带则带；相关人群能点则点。

## 八个高命中公式

1. 花钱踩坑式：花了 [金额]，我劝你 [反常识结论]
2. 数字对比式：[N] 个 AI 做同一件事，[结果反差]
3. 时间压缩式：[原本耗时] 的活，AI [新耗时] 搞定
4. 人群点名式：[人群]，[工具/功能] 真的该用了
5. 免费入口式：[工具][功能] 免费了，[一个限定/坑]
6. 卸载式：用了 [N] 天，我 [卸载/退款/续费] 了
7. 替代式：别再花钱买 [A] 了，[B] 够用
8. 反转式：都说 [A] 好用，测完我发现 [反转]

## 成稿闸（不过不算交）

1. 七要素 ≥2（推荐 2–3）
2. 四维总分 ≥80（好奇 30 / 相关 30 / 利益 20 / 可信 20）
3. 高权流量词必须带
4. 禁中庸解释尾（高分冲突后禁止续「人还得盯着」「其实还得…」）
5. 禁喊麦夸张：最 / 最屌 / 炸天 / 封神 / 天花板 / 吊打 / 遥遥领先
6. 承诺可兑现：未测不写「实测」
7. 交付：8 备选 → 四维表 → Top3；定稿一字不改

## 禁区

- 震惊、炸裂、封神、天花板、遥遥领先、吊打
- 最、第一、唯一、100%（广告法风险）
- 没测却写实测 / 亲测 / 一天 N 场
- 标点堆叠 ！！！ ？？？
- 中庸解释尾
- 空喊功能名（有产品无冲突、无场景、无动作）

## 已验证正例（可直接抄结构）

- WorkBuddy 一句话出 PPT，敢不敢上台
- 别再桌面里翻半小时，右键直接丢给 Buddy
- WorkBuddy 先别卸，豆包工作这样装
- 别再传文件了，WorkBuddy 右键就行 ← 本片用这条
  （造冲突「别再…了」+ 借势 WorkBuddy + 送好处「右键就行」= 85 分）
