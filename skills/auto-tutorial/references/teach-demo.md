# 教学演示轨（真机录屏带做）· v3.5.0

2026-10-25：六伟否定「截图推拉版」当上架教程。跟着做选题走本轨——像老师带做，能跟做；不要 26 秒快切。

## 何时用

- 上架、认证、收款、打包上传等**逐步点击**教程
- 用户明确说「实操演示」「老师教学」「跟着做」
- 默认画幅 **16:9 横屏**；片长 **45–90s**（可拆「上架篇 / 收款篇」）

不用本轨：纯种草钩子、只要利益开场的短爆点 → 走截图动态轨（仍禁花录）。

## 与 steps.json 的关系

1. 先有（或从图文改造）`steps.json`，`mode` 建议写 `"teach-demo"`。
2. 每步必有 `goal` / `do` / `see`，顺序 = 真实点击顺序。
3. `shots.before/after` 对本轨**不阻塞成片**（可空或作分镜参考）；成片证据是 `raw/screencast/*.mp4` + 剪辑时间线对 steps 的标注。
4. 仍禁止 AI 生成界面；缺真机页面就停，去打开 App/开放平台补录。

## 录屏硬规则

| 项 | 要求 |
|---|---|
| 画面来源 | WorkBuddy.app 或 https://open.workbuddy.cn 真实操作 |
| 单步停留 | ≥4–6s，或旁白该步说完再切 |
| 光标 | 真实鼠标/点击可见；不要挡关键按钮文字 |
| 隐私 | 证件号、手机号、邮箱、未授权侧栏裁切或录前遮挡 |
| 动作分级 | 同 steps-schema：`pay_stop` 不提交支付；`delete_cancel` 取消 |
| 花录 | 本轨可用系统/ffmpeg 录屏；**不要**用花录 Agent 剪辑冒充本流程 |

建议页面顺序（付费 Skill 上架示例，可按 steps 增删）：

1. 开放平台登录页 → 已登录后台  
2. 个人认证入口（若观众需看；已认证可口播带过并闪现状态）  
3. 发布管理 → 技能 → 创建/上传区  
4. 确认信息 + 分类  
5. 技能列表「审核中」  
6. 收入变现入口 + 开通条件（灰按钮）  
7. 付费设置示例（过审后；`pay_stop`）  
8. （可选）客户端市场「付费」搜索结果  

## 旁白（老师口吻）

- 用「你」：你打开…、你点左边…、这时你会看到…  
- 一步一事；数字与限制说清楚（zip≤3MB、两层目录、SKILL.md 字段）  
- 预估口播 **45–75 秒** 对应单集；超 90s 拆集，不靠倍速硬塞  
- 福利结尾：口播 closing.txt 原文；**画面禁止硬切大红底**——继续停在最后一帧真机画面叠字幕，或淡出到轻量结束卡  

## 声音与锁

- VoiceBox 档案：通过环境变量 `AUTO_TUTORIAL_VOICEBOX_PROFILE` 配置（**请换成你自己的声音档案 ID**；生成前按本机 VoiceBox 核验）  
- 锁文件：`AUTO_TUTORIAL_VOICEBOX_LOCK`（示例默认 `~/voicebox.lock`；占用则等待或按你本机约定排队；勿并行双开）  
- 语速：约 **1.2–1.3x**，全片统一  

## 工程目录（建议）

```
ROOT/
  PROGRESS.md          # ≤30 行
  script-plan.md
  steps.json           # mode=teach-demo
  narration.txt
  raw/screencast/      # demo.mp4 等；未录前可空
  scripts/record_demo.sh
  voice/
  edit/
  final.mp4            # 审阅通过后再有
```

未录、未渲时**不要**假装已有成片；PROGRESS 写明缺录屏/缺配音。

## 录屏脚本草案要点

工程内 `scripts/record_demo.sh` 应用 ffmpeg avfoundation：

- 视频设备：`Capture screen 0`（以 `ffmpeg -f avfoundation -list_devices true -i ""` 当时列表为准）  
- 输出：`raw/screencast/demo.mp4`  
- 本技能文档不要求无人值守长录；开录前确认窗口布局与登录态  

## 剪辑检查清单

- [ ] 每步 goal 在画面中出现过  
- [ ] 无单步 <4s 闪切（除非该步口播本身更短且已看清）  
- [ ] 片长 45–90s 或已拆集说明  
- [ ] 16:9；字幕可读；福利无大红底硬切  
- [ ] 封面 3:4 满幅撑满（非 16:9 截帧）  
- [ ] 隐私已处理；未误提交支付/删除

## 封面撑满（视频号 3:4 · 2026-10-29）

教学演示轨正文是 **16:9**，但交片封面必须是 **单独的 3:4（1080×1440）满幅图**：

1. 整幅撑满视频号封面位，禁止上下黑边/灰边。
2. 禁止「截一段 16:9 正文画面」直接当封面。
3. 与成片开场同风同题；少字利益标题；导出独立封面文件后 hub `--cover` 提交。
4. 检查清单加勾：封面 3:4 满幅、非 16:9 截帧。
