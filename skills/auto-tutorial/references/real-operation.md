# 实操取证闭环

## 先判断任务与工具

先写下本次要演示的一个可核验结果及完成标准，例如“在 WorkBuddy 调用指定技能生成文件，并打开文件确认内容”，不是“点几个按钮”。记录开始时间；60秒以内教程从制作到可播放并检查过的MP4须控制在10分钟，超时如实记账，不省核验。现有图文模式不需要重新实操。

查看当前可用的浏览器与桌面操控能力、截图保存方式、文件读取方式。网页用浏览器工具读取结构或截图；桌面用原生桌面操控能力读取界面或截图。WorkBuddy 内没有可用桌面操控工具时，明确是本次缺少工具/权限，而不是靠更多文字就获得能力；不要臆造接口。不要默认照搬 Codex 专属 cua API。仅必要登录、授权或工具权限缺失时请用户介入；提醒前播放 macOS Glass 提示音（可用时）。同一桌面只有一个操作者。

## 每次只推进一个可验证动作

循环：读取当前界面 → 根据实际文字/控件或新截图定位 → 执行一个动作 → 等待并重新读取状态 → 比较预期 → 保存有教学价值的关键截图。坐标必须来自本次截图，布局变化后重定位。优先语义定位；坐标点击只用于已观察的位置。返回 ok 不代表成功。发送后确认进入执行；不要重复发送，更不要误点已变成停止的按钮。

状态没变化，先检查焦点、遮挡、目标、加载或错误。允许一次有依据的替代定位；同一故障连续两次仍未解决时停止该路径并说明缺口，不能反复盲点。等待生成时可做独立准备；不能提前写“成功”旁白。不要为了画面变化修改无关数据、创建重复记录或触碰删除/发布等未获授权操作。

## 必须留下的证据链

入口（必要菜单上下文）、实际输入（完整关键条件）、执行后可见状态、实际结果。打开生成文件/页面并核对内容；成功提示、执行日志和文件存在都不能单独证明任务做对。失败和修正保留记录，不剪成一次成功。缺少哪个关键步骤就补哪个，不强制8—15张。

截图优先直接保存目标应用/标签内容。工具只返回图片时，检查是否支持导出到文件；不杜撰可下载路径。确需系统单张截图时先检查前台及目标窗口范围，排除其他应用；不得循环连续截图当录像。裁切区域依据本次实际尺寸，不能硬编码0,380等旧坐标。保留原图，入片副本裁掉标签页、书签、私聊、通知、客户身份及凭证；隐私用裁切或实色遮挡，不用模糊。逐张实际查看。

在项目 evidence.json 记录如下结构（实际内容由操作者填写，不能把示例当证据）：

```json
{
  "goal":"本次目标", "started_at":"带时区的真实时间",
  "steps":[
    {"id":"entry","kind":"entry","action":"实际动作","observed":"实际观察","shot":"assets/screenshots/01.png","checked":true},
    {"id":"input","kind":"input","action":"实际输入","observed":"输入已出现","shot":"assets/screenshots/02.png","checked":true},
    {"id":"execution","kind":"execution","action":"执行","observed":"实际状态","shot":"assets/screenshots/03.png","checked":true},
    {"id":"result","kind":"result","action":"打开作品核对","observed":"内容核验结论","shot":"assets/screenshots/04.png","checked":true}
  ],
  "result_verified":true,"privacy_reviewed":true
}
```

checked、result_verified 和 privacy_reviewed 只能实际检查后填写。同一截图可承担多个证据。scenes[].evidence_ids 指向相应 steps[].id；讲述的结果和数字必须能对应证据。说明卡标明示意，不能替代关键结果。检查脚本只检查结构、文件与引用，不证明真实性。

## 交给现有视频流水线

保留原来的图文成片模板与脚本；将已核验截图填入 scenes[].shot。按实际结果定稿旁白，然后配音、时间轴和剪辑。VoiceBox 按 project.json 里配置的 `voice.profile_name`（或 `profile_id`）核验档案，生成前核验存在，不得偷偷换音色。教程语速**固定1.5倍速（唯一值，不许降回1.35，脚本已做下限保护）**。开头0.2秒封面，默认1080×1920单画面，WorkBuddy系列标签“WorkBuddy实操”；用户当次明确选择其他画幅时从其要求。

对一张原图只做一层取景：远景交代入口、中景讲步骤、近景读输入/结果，必要时拉回。运镜有目的且缓入缓出，不能裁掉正在讲的文字。禁止假光标、点击、加载及输入动画。红白图解只解释方法。先看入口、输入、结果与转场取景，再导出；导出后核对时长帧数，实际看完听完，检查字幕、声音、画面及隐私。机器检查不算实际审阅。交付同一份最新版MP4的播放预览与下载链接，记录结束时间和耗时。只交付审阅，不自动批量或对外发布。
